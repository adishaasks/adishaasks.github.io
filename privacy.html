Privacy Policy

Last updated: 8 October 2026

This policy explains how Adisha Channel Tools (the "Tool") and this website handle information. The Tool is private software used only by the owner of the "Adisha Asks Brahma & AI" channel to publish the channel's own videos. Questions go to adishaasks@gmail.com.

1. Who can use the Tool

Only the channel owner signs in to the Tool, and only with the channel's own Google, YouTube, Facebook and Instagram accounts. The Tool is not offered to the public. It does not collect personal information from viewers, followers or anyone else.

2. Information the Tool accesses

When the owner grants permission, the Tool accesses only the channel's own accounts:

  • YouTube (YouTube API Services): channel name and ID, the channel's own videos and their details, uploading new videos and thumbnails, and the channel's own statistics such as views and watch time.
  • Facebook and Instagram (Meta Graph API): the channel's Facebook Page and linked Instagram professional account, publishing the channel's own Reels and posts, and their statistics such as reach and views.
  • Sign-in tokens: the access and refresh tokens that Google and Meta issue so the Tool can act for the owner.

3. How the information is used

  • To upload and schedule the channel's own videos, thumbnails, titles and descriptions.
  • To read the channel's own statistics, so the owner can see how videos perform.

The information is not used for advertising, not sold, and not used to build profiles of anyone.

4. Where it is stored

Sign-in tokens are stored only on the owner's private computer and private server, in files that are not public. Statistics are stored only in the owner's private reports. Nothing is stored on this website.

5. Sharing

The Tool does not share, sell, rent or transfer any information to anyone. Information is sent only to Google (YouTube) and Meta (Facebook and Instagram), as needed to carry out the actions the owner requests.

6. How long it is kept

  • Sign-in tokens are kept until the owner revokes access or the token expires.
  • Statistics read through YouTube API Services are kept for no longer than 30 days unless refreshed, and are deleted when no longer needed.
  • When access is revoked, the stored tokens are deleted.

7. Google and YouTube

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Information handled by Google is also covered by the Google Privacy Policy.

The Tool's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke the Tool's access to a Google account at any time on the Google security settings page.

8. Meta (Facebook and Instagram)

Information handled by Meta is covered by the Meta Privacy Policy. You can remove the Tool's access in Facebook under Settings and privacy, then Settings, then Business integrations.

9. Deleting your data

The Tool holds no data about anyone other than the channel owner. To ask for deletion of any information, email adishaasks@gmail.com. Requests are completed within 30 days. Revoking access as described above also stops all further access straight away.

10. This website

This website is a static site hosted on GitHub Pages. It uses no cookies, no analytics and no forms. GitHub may log basic technical information, such as IP addresses, to run and secure its service, as described in the GitHub Privacy Statement. The page fonts load from Google Fonts.

11. Children

The Tool and this website do not knowingly collect personal information from anyone, including children. Adisha is an animated character.

12. Changes

If this policy changes, the new version will be posted on this page with a new "Last updated" date.

13. Contact

Email: adishaasks@gmail.com
